# 0002 — Pydantic models are the device protocol source of truth

Status: accepted (scaffold)

## Context
Board and cloud must agree on message shapes; hand-maintained copies drift.

## Decision
`packages/device_protocol` (pydantic v2) defines the envelope, payloads, topics and versioning.
JSON Schemas and OpenAPI under `contracts/` are generated by `scripts/export_contracts.py`; a
contract test and a CI step fail if they are stale. Fixtures under `contracts/device/fixtures`
are exercised by contract tests.

## Consequences
- Python on both sides shares the same code: the host PC (CPython 3.10+, ADR 0004) and the
  cloud (3.12). The package must stay 3.10-compatible.
- If a future board runs the protocol on-device without pydantic (e.g. MicroPython), generate
  a light validator from the JSON Schemas rather than hand-writing one.
